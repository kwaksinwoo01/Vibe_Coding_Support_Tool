# Vibe_Coding_Support_Tool
이 프로그램은 AI 코딩 에전트로 대규모 코딩프로그램을 만들때 바이브 코딩으로 개발하는 고질적인 문제를 최소화 하고 작업을 효율적으로 수행하기 위한 기능을 최대한 지원하기 위해 만들었습니다. 코딩에 대하 지식일 배우기에는 많은 정보와 느린 개발속도를 해결하기 위한 나만의 커스텀 AI 를 만들수 있을것 입니다. 
모든 코딩을 AI 에게 맡기는건 AI의 크리딧 소모가 많아지면서 개발이 느려지고 명확한 지시가 없다면 램덤으로 결정하면서 일관성 없는 코드가 만들어집니다. 특히 코딩 분량이 10개 파일만 넘어가도 AI는 일관성이 없어집니다. 
따라서 이프로그램은 대규모 코딩 프로그램 개발에 특화된 작업계획서 생성 및 실행 도구로 당신의 작업 계획서를 관리하고 실행해줄것 입니다.

*주의*: 이 도구는 사용자의 역량에 따라 효율이 달라집니다. 자세한 코드 계획이 있을수로 정밀해지며 그렇지 않으면 효율을 보기 어렵습니다, 또한 소규모 프로그램의 경우 효과가 미미하며 전문적인 지식이 있다면 사용안하는게 작업 속도가 빠를수도 있습니다.

This program was created to minimize the chronic problems associated with Vibe Coding when developing large-scale coding programs using AI coding agents and to maximize functionality for efficient work. Learning coding knowledge is a complex process, and you'll be able to create your own custom AI to address the slow development process.

Leaving all coding to AI increases the AI's credit consumption, slowing down development. Without clear instructions, AI will make random decisions, resulting in inconsistent code. In particular, if the coding volume exceeds 10 files, the AI ​​will become inconsistent.

Therefore, this program is a specialized work plan creation and execution tool for large-scale coding program development. It will manage and execute your work plan.

*Caution*: This tool's effectiveness depends on the user's skill level. A detailed code plan increases precision, while an otherwise inefficient one will be less effective. Furthermore, it may be ineffective for small-scale programs. If you have specialized knowledge, it may be faster to disregard it.
